01 // WHAT IT DOES

Less “did I forget something?”

CampusBoop does not replace the school system. It helps you remember the steps around it.

01

Check-in reminders

Open your configured login and check-in pages without hunting through tabs or bookmarks.

02

Commit + push Boops

While you work in VS Code, Boop can remind you to protect your work with regular commits and pushes.

03

Break reminders

Take a ten-minute quiet period, resume early, or keep working. You control the pace.

04

Daily checkout

When you finish, mark yourself checked out locally and stop the reminders for the day.

05

Your schedule

Limit automatic reminders to selected weekdays and hours so Boop stays silent outside school time.

06

Start with your PC

Windows and Linux can both launch CampusBoop automatically when you sign in.

Important: CampusBoop opens the school pages, but it does not submit HvA/UvA check-in or checkout forms automatically. You still review and submit the actual school action yourself.

04 // INSTRUCTIONS

After installation.

The installers also print a short version of these instructions and a clickable link back here when supported by the terminal.

WINDOWS

First start

Open CampusBoop from the Start Menu, CampusBoop.exe, or a new terminal with campusboop. Choose whether the helper may stay in the background and whether it should start when you sign in.

LINUX

First start

Run campusboop. CampusBoop starts a local-only interface and opens it in your normal browser. Use campusboop --autostart-on to start it automatically when you sign in.

BOTH

School links

Open Settings and enter your HTTPS school login and check-in links. You can give Check-in 1 and Check-in 2 different names and URLs.

BOTH

Daily workflow

Use “Already checked in today” after you have completed the real school check-in. Use “Checked out for today” when you are finished to stop reminders until the next day.

BOTH

Removing CampusBoop

campusboop --uninstall removes the installed app but keeps your local settings. campusboop --purge removes the app and CampusBoop’s saved local settings.

LINUX NOTE

VS Code detection

On X11, CampusBoop can use xdotool when available to check whether VS Code is foreground. On Wayland or without it, the fallback checks whether VS Code is running.

05 // PRIVACY & LOGIN

Your school account stays yours.

Windows

Personal login is optional. The Windows v1.0 app can store its optional saved login using Windows DPAPI for your Windows account and limits autofill to the configured trusted HvA/UvA ADFS login host. MFA/phone verification remains manual.

Linux

The Linux v1.0 build does not store your HvA/UvA password. School authentication opens in your normal browser, so browser/session security remains with your existing browser setup.

No automatic submission

CampusBoop records “checked in” and “checked out” only as local reminder status. It does not claim that action was registered by the school system.
