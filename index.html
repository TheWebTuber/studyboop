01 // WHAT IT DOES

Useful when you need it. Quiet when you don't.

01

Check-in & checkout

Keep your own school links ready and mark your local CampusBoop status so reminders know when to stop.

02

Startup reminder

Optionally get one delayed reminder after signing in to your computer instead of an instant popup during boot.

03

Smart VS Code reminder

If you still have not checked in, CampusBoop can remind you when you actually start working in VS Code.

04

Commit + break Boops

Once you're checked in, optional work reminders help you remember commits, pushes and short breaks.

05

Student tools

Print, Top up and Library are ready at the bottom and remain fully editable for your own shortcuts.

06

Flexible schedule

Use a typical finish time or set your own weekly hours. CampusBoop resets the school day automatically.

CampusBoop does not submit school forms for you. It opens the official pages and keeps local reminder status. You still review and submit the real HvA/UvA action yourself.

03 // INSTRUCTIONS

First start is intentionally simple.

1

Choose HvA or UvA

CampusBoop prepares the matching Print, Top up and Library defaults. All of them remain editable.

2

Choose reminder behavior

Enable startup, smart VS Code and checkout reminders, then choose the startup delay.

3

Add your check-in links

Project / Check-in 1 and 2 can share one URL or use separate links. Rename them however you want.

4

Use CampusBoop normally

Mark yourself checked in only after the real school check-in succeeds. Mark checked out when your school day is finished.

WINDOWS

Optional login autofill

Windows can optionally save your school ID/password locally using Windows DPAPI. Autofill is limited to the selected trusted HvA/UvA login host. MFA remains manual.

LINUX

Browser login

Linux opens HvA/UvA authentication in your normal browser. CampusBoop does not store your school password on Linux.

WINDOWS

Remove manually

Exit CampusBoop. Search for CampusBoop in Windows → Open file location. If that opens a shortcut, use Open file location on the shortcut again, then delete the actual CampusBoop app folder and remove the shortcut. Delete %LOCALAPPDATA%\SchoolCheckInHelper only if you also want to erase settings/login data.

LINUX

Remove with one command

campusboop --uninstall removes the app but keeps settings. campusboop --purge removes both app and local CampusBoop settings.

LINUX

VS Code detection

On X11, CampusBoop uses xdotool when available for foreground detection. On Wayland or without it, it falls back to checking whether VS Code is running.

TROUBLESHOOTING

Windows first-launch protection

CampusBoop is an independent unsigned student app, so Windows may show SmartScreen on a direct ZIP launch. The quick installer verifies the exact release hash before installing.

04 // PRIVACY

Your school account stays with you.

Local settings

CampusBoop stores reminder settings and local checked-in/checked-out state on your own computer.

No school database access

CampusBoop does not query an HvA/UvA student database or claim that a school check-in succeeded.

Official pages stay official

Print, top-up, library and authentication actions open the configured official web services rather than being processed by this website.
